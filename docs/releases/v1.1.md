# v1.1 — 主要结果与多 sheet 管理

- 主要结果集中为峰值应力、峰值轴力、弹性模量和泊松比，其余结果折叠到详情。
- 新增轴力列读取；缺失时支持输入截面积，由应力换算轴力并标注来源。
- 支持同一工作簿多个 sheet 按同一模板导入、试样切换和保存全部试样进度；计算与导出仍按当前试样执行。
