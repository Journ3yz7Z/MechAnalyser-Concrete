# MechAnalyser-Concrete 1.7

基于本地 1.6.4 继续修改，保留原来的导入校验及计算方法。

- 主要结果左侧保留峰值应力、峰值轴力、弹性模量和泊松比；右侧显示轴向、环向拟合的 R² 与 n。R² 显示六位小数，n 为实际同步拟合点数。选区变化时同步更新，失败时不保留旧 R²。
- 选择三轴压缩试验后显示围压选项：2.5、5、7.5、10 MPa 和自定义数值。切换为单轴时隐藏，保留已输入值；没有围压的旧记录显示未填写。
- 三轴信息卡在试验名称与材料之间增加“围压：… MPa”，同步到交互图、全范围图及局部图。围压保存在分析记录中，并写入结果表。
- 全范围导出图也根据加长后的信息卡执行位置避让。

围压是本版新增的试验信息，不自动修正应力、扣除围压或改变 E、泊松比计算。请按实际试验输入。

完整保留程序目录与 `_internal`，运行 `MechAnalyser-Concrete.exe`。旧版本无需删除。本版现补充公开归档。
