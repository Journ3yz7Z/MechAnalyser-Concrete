# MechAnalyser-Concrete 1.8

基于本地 1.7 更新，保留原有计算方法。

- 交互叠加图及两种导出图，在 E、ν 旁增加轴向、环向应力回归的 R²（保留三位小数）；ν 保留四位小数。
- 顶部增加 PNG、SVG 多选框；勾选两项时，全范围图和局部放大图均导出两种格式。至少须选择一种。
- “选择拟合区间”新增“将当前区间设为默认”。保存选择依据及上下限，重启和新导入时生效；打开已保存分析仍使用其原有区间。工厂初始区间为峰值比例 0.2～0.5，仍须人工检查适用性。
- 默认区间保存在用户 AppData/Roaming/MechAnalyser-Concrete/preferences.json，独立于程序目录和原始数据。

泊松比仍采用 ν=-E/k横；R²环是轴向应力—环向应变拟合的决定系数，并非泊松比准确性的直接证明。旧版、源数据和既有分析记录均保留。

本版现公开发布于项目 GitHub 仓库。
