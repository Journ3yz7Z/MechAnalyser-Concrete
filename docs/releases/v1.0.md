# v1.0 — 初始混凝土工作区

- 基于原 MechAnalyser 架构新增中文混凝土压缩分析界面，按试样导入 Excel 轴向应变、环向应变和轴向应力。
- 明确设置列、单位和符号；限定加载分支并选择拟合区间，使用同步有效点计算回归模量和应变回归泊松比。
- 支持拖动选区、结果详情、数据问题检查、分析记录保存与恢复，以及 Excel、CSV 和图片导出。
