# MechAnalyser-Concrete

基于 [ksonter95/MechAnalyser](https://github.com/ksonter95/MechAnalyser) 改造的中文材料压缩试验分析桌面程序。用于逐试样检查 Excel 中的轴向应变、横向应变和轴向应力，选取拟合区间，计算模量与泊松比，并导出可复核的结果和图片。

本仓库由 [Journ3yz7Z](https://github.com/Journ3yz7Z) 维护，是独立改造版本，不是原作者的官方发行版。上游原作者版权和 MIT 许可完整保留，见 [LICENSE](LICENSE) 与 [SOURCE_NOTICE.md](SOURCE_NOTICE.md)。

> 1.8 的 Windows 发布包缺少 SVG 后端。需要 SVG 导出请下载 1.8.1；1.8.1 已增加打包后两种 SVG 导出组合的自检。

## 下载与启动

到 [Releases](https://github.com/Journ3yz7Z/MechAnalyser-Concrete/releases) 下载 `MechAnalyser-Concrete-v版本号-Windows-x64.zip`。解压整个文件夹，再运行 `MechAnalyser-Concrete.exe`。必须保留旁边的 `_internal` 文件夹，不能只复制 exe。

这是 Windows x64 便携程序，无需另装 Python。发布包未做代码签名。最新版公开归档为 **1.8.1**；历史版本功能不同，详见 [更新记录](CHANGELOG.md)。每个版本提供 SHA-256 校验文件。

## 功能与使用流程

1. **导入 Excel**：选择一个或多个 sheet，以一个 sheet 为列映射模板，指定轴向应变、横向/环向应变、轴向应力列，以及各列真实单位和符号。多 sheet 导入仍按试样分别分析，不会把曲线合并。
2. **轴力来源**：优先读取指定的轴力列；没有轴力列时，可输入试样截面积，由应力换算轴力。未提供这两项时不生成轴力值。
3. **核对试件信息**：三轴试验可选围压 2.5、5、7.5、10 MPa 或自定义，信息卡同步显示。填写编号、试验类型、材料、水泥/细骨料比例、含水率、压注压强、压注时间和养护天数。零压注压强时，压注时间输入禁用，信息卡隐藏这一项。
4. **限定加载分支**：检查程序建议的分支起止行，再按分支峰值应力比例、绝对应力或轴向应变选择拟合区间；可拖动区间边界或输入上下限。点击“将当前区间设为默认”可保存选择依据及上下限，重启和新导入时生效；打开旧分析保留原选区。
5. **检查结果**：主要结果为峰值应力、峰值轴力、弹性模量和泊松比；右侧显示轴向、环向 R² 与 n；展开详情可查看各回归斜率、截距、R²、有效同步点数及提示。默认不强制拟合线过原点。
6. **保存进度**：“保存分析”生成当前试样 `.mca.json`；“保存全部试样进度”生成 `.mcw.json`；“打开分析”恢复记录和设置，并核对源文件状态。
7. **导出当前试样**：生成结果 Excel、实际拟合数据 CSV、分析记录，以及全范围图和横轴固定为 −0.005～0.005 的局部放大图。顶部可多选 PNG、SVG；每种格式均导出两张图。图中 E、ν 旁分别显示轴向和环向拟合 R²。两张图使用同一计算结果，局部图裁剪不会改变拟合点。

## 计算方法

计算使用同一批有效同步行；内部应变单位为 mm/mm，应力为 MPa，轴向压缩为正、横向膨胀为负。用户必须核实通道物理含义，程序不会把位移自动认定为应变，也不会自动平滑、重排或取绝对值。

在所选区间内分别作最小二乘回归：

$$\sigma=a_a+E\varepsilon_a,\qquad\sigma=a_h+k_h\varepsilon_h$$

**1.6～1.8 的主要泊松比**使用斜率比：

$$\nu=-\frac{E}{k_h}$$

计算时两个斜率均使用 MPa；界面中的 E 可换算为 GPa 显示。该表达对应程序采用的 ASTM D7012-14 式 (7) 斜率比方法。**采用这个公式不等于试验、选区和材料已经满足整部标准。** 当前 E 是所选区间的回归模量；1.8 初始默认 0.2～0.5（旧版为 0.2～0.4）仅为初始选择，不是自动判定的标准区间。

**1.0～1.5.1 的主要泊松比**使用横向应变对轴向应变的回归：`εh = a + b εa`，取 `ν = −b`。此结果在 1.6 起保留为参考值 `nu_strain`。有噪声或非线性时，两种回归结果可能不同，不应混用。

选区点数不足、应变几乎不变或斜率不适用时，程序给出错误或警告，不把失败结果替换为零。低 R² 和异常符号需要结合原始曲线检查。

## 适用边界与已知限制

- “单轴/三轴压缩试验”选项用于试验信息标注；不会自动扣除围压、计算偏应力或实现完整三轴本构分析。
- 本程序不自动建立完整混凝土本构模型，也不负责验证传感器标距、试件几何、加载制度或标准符合性。
- 自 1.6.4 起，多 sheet 校验前九列及额外选用列的列名、单位和顺序；未使用的辅助列表头差异仅提醒。不能仅凭看起来相似的表头假定单位相同。
- 默认试件参数只是输入初值，必须按实际条件核对；默认养护为 28 天、材料为水泥砂浆、配比 1:2、含水率 13%、压注压强 0 MPa、压注时间 24 小时。
- 目前导出针对当前试样，不是批量报告生成器。论文图的标注位置有自动避让，但仍需检查最终图像。
- 中文排版优先宋体，英文数字优先 Times New Roman。字体由本机提供，没有将这些商业字体作为项目文件分发。

## 来源与改造范围

上游基准提交：[`76d8ea65704edee4bffa385eb404e557f47401c7`](https://github.com/ksonter95/MechAnalyser/commit/76d8ea65704edee4bffa385eb404e557f47401c7)。原项目提供材料力学数据分析框架及试验模块。本项目继续使用其 `Analyser / Data / Phase` 架构、试验注册机制、Pint 单位体系和 PySide6/PyQtGraph 界面；新增 `mech_analyser/experiment/concrete/` 工作区，而非重新实现后仅引用项目名称。

主要改造包括：Excel 同步三通道导入、多 sheet 试样管理、人工选区回归、轴力来源追踪、结果折叠展示、中文材料参数、双范围论文图、分析快照保存与恢复、数据问题报告，以及 1.6 的泊松比主算法调整。逐版范围见 [CHANGELOG.md](CHANGELOG.md)。原有通用模块保留，可用 `--legacy` 打开原界面；本次公开验证集中在混凝土工作区。

历史 exe 保留原文件内容，重新打包时清除了项目私有示例图、原始试验数据和含本地路径的交付说明，并补充公开说明及依赖许可。发布日期为本次公开归档日期，不冒充原开发日期。

## 从源码运行（Windows / Python 3.12）

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-windows-lock.txt
.\.venv\Scripts\python.exe run_mechanalyser.py
```

执行混凝土模块测试（使用程序生成的合成数据）：

```powershell
.\.venv\Scripts\python.exe -m pytest tests/concrete -q
```

构建便携版：

```powershell
powershell -ExecutionPolicy Bypass -File build_windows.ps1 -Python .\.venv\Scripts\python.exe
```

`requirements-windows-lock.txt` 是验证环境的依赖版本清单；`requirements.txt` 保留原项目依赖清单。构建结果位于 `dist/MechAnalyser-Concrete/`，分发时应包含整个目录和许可文件。

## 数据与隐私

本公开仓库不提供研究者的真实试验工作簿、分析快照、结果表、论文图或个人文件路径。测试使用明确标为 `SYNTHETIC_TEST_ONLY` / `TEST` 的程序生成数据；这些数值不代表实验结果。运行库可能包含上游依赖自带的图标、颜色表和演示数据，它们不是本项目的试验数据。

程序在本地分析数据；导出的 `.mca.json`、`.mcw.json` 和结果文件会包含数据快照、源文件位置及试件信息，分享这些文件前请自行核对。报告问题时优先提供最小合成示例，不要把真实研究数据上传到 Issue。
